# Closer: the same 4Ds on a task with no code

**Point:** the habits are not about Claude Code. They work for any task, with any AI tool.

**Task:** draft a one-page *Compensation Approval Policy* for a new airline's customer-service team.
(The code demo's `COMPENSATION_POLICY.md` is a finished example; do not show it until the end.)

Use the same four steps. Give the audience five minutes to fill the worksheet, then run it live.

## 1. Delegation
| Piece of the work | AI | Human |
|---|---|---|
| Find out what a typical policy covers | | |
| Draft the structure and first wording | | |
| Choose the actual dollar limits | | |
| Decide who may approve what | | |
| Check it against local consumer-protection rules | | |
| Sign it off | | |

*Hint:* limits, authority, and legal compliance are human decisions. AI can propose options and draft.

## 2. Description
Fill in the blanks and send:

```
PRODUCT: I need a one-page compensation approval policy for [audience], covering [topics].
PROCESS: Start by asking me up to five questions you need answered. Then draft it. List your assumptions separately.
PERFORMANCE: Plain language. Short sentences. If I ask for something unusual or risky, say so before doing it.
Here is what I already decided: [your limits and roles].
```

## 3. Discernment
Read the draft with these questions:
- Which statements are facts, and which did the AI invent? Highlight each number.
- What rule would a careful reviewer say is **missing**? (Segregation of duties? Record keeping? Appeals?)
- Does it sound confident about something it cannot know, such as local law?
- Does it follow your limits exactly, or quietly change them?

Then feed back: "You assumed X. That is wrong because Y. Revise."

## 4. Diligence
- Who verifies the legal and numeric claims before anyone relies on this?
- Do the people who will use the policy know AI helped draft it?
- Who is the named owner? (A person, not "the AI".)
- What private information, if any, did you put into the prompt, and was that allowed?

## Debrief
Same four habits, completely different task. Which D did you skip most naturally?
Which one would have saved you last time you used AI at work?

## The pocket card (take this away)

| D | One question to ask yourself |
|---|---|
| **Delegation** | What should the AI do, and what is still mine to decide? |
| **Description** | Have I said what I want, how to work, and how to behave with me? |
| **Discernment** | What would I check before believing this? What is missing? |
| **Diligence** | Would I be comfortable owning and disclosing this result? |
